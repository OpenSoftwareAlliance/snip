# OSA Snip

**Self-hosted code snippets and gists.**

Open source alternative to **Google Keep (snippets)**. Part of the [Open Software Alliance](https://github.com/OpenSoftwareAlliance) suite.

</div>

---

## Features

- Create and share code snippets and gists
- Syntax highlighting and Markdown rendering
- Private, unlisted and password-protected posts
- Multiple files per post

## Tech stack

- **Current:** Next.js App Router + TypeScript, Prisma + Postgres
- **Target:** Next.js + TypeScript on Cloudflare Workers (see [migration research](https://github.com/OpenSoftwareAlliance/snip/issues/2))

## Roadmap

- [Open source landscape research](https://github.com/OpenSoftwareAlliance/snip/issues/1)

## Self-hosting

Installation and configuration follow the upstream project for now: see the [Drift documentation](https://github.com/MaxLeiter/Drift#readme).
